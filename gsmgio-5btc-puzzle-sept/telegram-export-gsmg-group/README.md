## Contents

- `result.json` - the export exactly as Telegram Desktop produced it (full message objects, original
  ordering). Everything else in this folder is derived from this file.
- `by-year/` - the same conversation flattened to text and split per year (`2019.txt` ... `2026.txt`).
  One block per message: timestamp, author and message id, separated by dashes.
- `extracts/` - per-author slices used for research:
  - `extracts/jrk-messages.txt` - every text message of group member "Jrk Bgrt" (`user9815232`),
    492 messages, 2019-04-20 .. 2026-09-01.
  - `extracts/jrk-name-matches-other-account.txt` - messages of a second account whose display name
    matches "Jrk" (`Double shot of Jameson for Jrk`, `user8325382499`), 94 messages,
    2026-01-29 .. 2026-02-15.
